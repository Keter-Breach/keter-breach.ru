PROJECT: KETER

СИТУАЦИОННЫЙ СИМУЛЯТОР СДЕРЖИВАНИЯ // ЗОНА 19

[ПРОТОКОЛ АВАРИИ: ВСЕ СЕКТОРЫ ОБЕСТОЧЕНЫ]

[ЦЕНТРАЛЬНЫЙ СПРАВОЧНИК АНОМАЛИЙ // PROJECT: KETER]

Файлы автоматически восстанавливаются из фрагментов оперативной памяти комплекса.

• SCP-173 («Скульптура»)

Класс: Евклид. Подвижна вне зоны видимости. Ломает шею у основания черепа. {ДАННЫЕ УДАЛЕНЫ}.

[ФОТО-МАТЕРИАЛ ЗАБЛОКИРОВАН]
Встретьте объект на Уровне 1

• SCP-049 («Чумной доктор»)

Класс: Евклид. Пытается «вылечить» Поветрие. Касание приводит к {ДАННЫЕ УДАЛЕНЫ}.

[ФОТО-МАТЕРИАЛ ЗАБЛОКИРОВАН]
Встретьте объект на Уровне 1

• SCP-999 («Щекоточный монстр»)

Класс: Безопасный. Оранжевая эластичная масса. Вызывает приливы эйфории и подавляет {ДАННЫЕ УДАЛЕНЫ}.

[ФОТО-МАТЕРИАЛ ЗАБЛОКИРОВАН]
Найдите объект на Уровне 0

• SCP-096 («Скромник»)

Класс: Евклид. Впадает в ярость, если посмотреть на его лицо. Скорость бега до {ДАННЫЕ УДАЛЕНЫ} км/ч.

[ФОТО-МАТЕРИАЛ ЗАБЛОКИРОВАН]
Встретьте объект на Уровне 2

• SCP-076-2 («Авель»)

Класс: Кэтер. Бессмертный воин из куба. Материализует клинки из пространственных {ДАННЫЕ УДАЛЕНЫ}.

[ФОТО-МАТЕРИАЛ ЗАБЛОКИРОВАН]
Выживите при штурме на Уровне 2

• SCP-682 («Неуязвимая рептилия»)

Класс: Кэтер. Абсолютная регенерация. Ненавидит всю жизнь. Уничтожил сектор {ДАННЫЕ УДАЛЕНЫ}.

[ФОТО-МАТЕРИАЛ ЗАБЛОКИРОВАН]
Доберитесь до Сектора Кэтер

[БЛОК ЗАДЕРЖАНИЯ D-CLASS // СЕКТОР {ДАННЫЕ УДАЛЕНЫ}]

СУБЪЕКТ: D-9341 (Бывший доктор {ДАННЫЕ УДАЛЕНЫ}, разжалован за нарушение протокола).

СИТУАЦИЯ: Воют сирены аварийного сброса. Зона 19 содрогается от взрывов. Гермозатвор заклинило. Из вентиляции доносится хлюпанье. На окровавленном экране горит надпись: «Внимание! ИИ-079 заблокировал сектор. Подтвердите биологическое существование».

ТЕСТ СЛУЖБЫ БЕЗОПАСНОСТИ ЗОНЫ:

«В камеру SCP-173 вошли 12 сотрудников класса D. Трое моргнули — Скульптура мгновенно сломала им шеи. Двое запаниковали и побежали к выходу — устранены охраной. Еще 4 человека были утянуты в {ДАННЫЕ УДАЛЕНЫ}. Сколько живых сотрудников осталось внутри тестовой камеры?»

[СЕТЬ ТЕХНИЧЕСКОГО ОБЕСПЕЧЕНИЯ // ДОПУСК: УРОВЕНЬ 0]

МЕСТО: Технические туннели сектора снабжения Зоны 19.

СЮЖЕТ: Вы выбрались из камеры. Из-за угла выкатывается оранжевая масса — это SCP-999 («Щекоточный монстр»). Липкий страх немного отступает. Рядом лежит КПК погибшего электрика с фрагментом записи: «Объект прошел через {ДАННЫЕ УДАЛЕНЫ}...»

ПЕРЕХВАТ ЛОГОВ (ОТДЕЛ СНАБЖЕНИЯ // СТАТУС: ТРУДЯГА):

"Ребята из лазарета кодируют свои терминалы простым русским словом, обозначающим профессию Чумного доктора. Слово из 5 букв. Подсказка: "медик"."

[АРХИВ МЛАДШИХ ИССЛЕДОВАТЕЛЕЙ // ДОПУСК: УРОВЕНЬ 1]

СЕКТОР: Медико-биологический блок сдерживания Евклидов.

СЮЖЕТ: Экран мигает. Вы видите медицинские карты объектов. Внезапно по громкой связи раздается металлический скрежет: «Внимание! Сдерживание объекта SCP-096 («Скромник») сорвано! Скорость движения {ДАННЫЕ УДАЛЕНЫ}!» Дверь вырывает с корнем.

ЭКСТРЕННАЯ СИТУАЦИЯ СДЕРЖИВАНИЯ:

Из пролома появляется бледное гуманоидное существо. Оно закрывает лицо руками и истошно кричит. Что делать, чтобы не умереть?

[ОБОРОННЫЙ СЕРВЕР // СЕКТОР СТАРШИХ ИССЛЕДОВАТЕЛЕЙ // УРОВЕНЬ 2]

СЮЖЕТ: Вы на мостике наблюдения. Снизу идет бой: из кубического саркофага вырвался SCP-076-2 («Авель»). Он шинкует МОГ на {ДАННЫЕ УДАЛЕНЫ}.

Капитан МОГ кричит в рацию: «Оператор, вводи девиз Фонда на русском языке, чтобы разблокировать центральный ядерный пульт!»

[ЗАПРОС АВТОРИЗАЦИИ СЕТИ]:

Введите три главных каноничных слова девиза Фонда через пробел (обезопасить удержать сохранить):

[СЕКРЕТНЫЙ ЯДЕРНЫЙ ТЕРМИНАЛ // ДОПУСК: {ДАННЫЕ УДАЛЕНЫ}]

СЮЖЕТ: Вы получили контроль над Альфа-боеголовками. Но датчики фиксируют новую угрозу — в подземных резервуарах проснулась SCP-682 («Неуязвимая рептилия»). Протокол {ДАННЫЕ УДАЛЕНЫ} провален.

Чтобы связаться с Администратором, подтвердите личность Директора.

КВАНТОВЫЙ ЗАПРОС СВЯЗИ С АДМИНИСТРАЦИЕЙ:

Введите фамилию бессмертного доктора Фонда, чей разум заперт в амулете (5 букв).

[ДИРЕКЦИЯ ЗОНЫ 19 // КАБИНЕТ АДМИНИСТРАТОРА // УРОВЕНЬ 4]

СЮЖЕТ: Вы вошли под учетной записью доктора Брайта. Высший Совет Смотрителей O5 запрашивает Классификацию амнезиака для полного стирания памяти свидетелей инцидента {ДАННЫЕ УДАЛЕНЫ}.

КРИПТОГРАФИЧЕСКИЙ ТЕСТ СЛУЖБЫ БЕЗОПАСНОСТИ:

Введите класс этого амнезиака одной большой русской буквой.

[ЦЕНТРАЛЬНЫЙ СЕРВЕР НАДЗОРНОГО СОВЕТА O5 // ТАУМИЭЛЬ]

ПОЛЬЗОВАТЕЛЬ: O5-13 ({СМОТРИТЕЛЬ}).

СЮЖЕТ: Перед вами открываются файлы SCP-001 («Страж Врат»). Вы узнаете правду: Фонд удерживает реальность от распада. Но прямо сейчас сектор Кэтер уничтожается рептилией.

ДИРЕКТИВА СМОТРИТЕЛЕЙ:

«Мы существуем во тьме, чтобы вы жили в свете. Немедленно эвакуируйтесь в отсек кислотного удержания и примените {ДАННЫЕ УДАЛЕНЫ}.»

[ВНИМАНИЕ: СЕКТОР КЭТЕР // АВАРИЙНЫЙ ОТСЕК УДЕРЖАНИЯ]

СЮЖЕТ: Терминал полыхает красным! Огромная SCP-682 крушит стены. Из вентиляции лезет SCP-1048, а из темноты проступает SCP-106.

ФИНАЛЬНЫЙ ТЕСТ ФОНДА:

Чтобы залить бак кислотой и усыпить рептилию, введите позывной Мобильной Опергруппы («Девятихвостая лиса») в формате "название-число".

[ВЗЛОМ СИСТЕМЫ // ПОВСТАНЦЫ ХАОСА // CI-TERMINAL]

СТАТУС: Хакерский прокси-канал развернут Дельта-Командованием.

СЮЖЕТ: Из динамиков доносится голос: «Отличная работа, агент. Смотрители лгали тебе. Мы готовы подорвать {ДАННЫЕ УДАЛЕНЫ}».

ШИФР ДЕТОНАЦИИ ДЕЛЬТА-КОМАНДОВАНИЯ:

Введите кодовое название штурмовой ячейки — имя мифического многоголового чудовища (5 букв).
