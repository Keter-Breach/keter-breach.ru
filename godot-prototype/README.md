# Keter Breach — Godot Prototype

Первый автономный прототип переноса Keter Breach на Godot 4.x.

## Что уже заложено
- FPS-персонаж на CharacterBody3D: WASD, Shift, мышь, гравитация и коллизии.
- Процедурно собранный промышленный коридор D-12.
- Красные аварийные источники света, холодные потолочные лампы, туман и кинематографичная тональная карта.
- Минимальный HUD и цель прохождения.
- Рендерер Compatibility для более широкой совместимости.

## Запуск
1. Установить Godot 4.x (Standard, не .NET).
2. В Godot Project Manager нажать Import.
3. Выбрать файл `project.godot` в папке `godot-prototype`.
4. Запустить проект клавишей F6/F5.
5. Управление: WASD, Shift — бег, мышь — обзор, Esc — отпустить курсор; клик снова захватывает мышь.

## Примечание
Это стартовая сцена для проверки управления и атмосферы, а не полный перенос. Перед распространением необходимо открыть проект в Godot и проверить запуск на целевых системах. Существующая Three.js/Electron-версия не изменяется.
