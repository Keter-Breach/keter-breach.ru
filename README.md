# PROJECT: KETER

Браузерный прототип survival-horror в эстетике VHS и внутренней системы наблюдения Фонда SCP.

## Запуск

Откройте `index.html` через локальный статический сервер или опубликованную версию проекта. Three.js загружается с CDN; для запуска 3D-сцены требуется WebGL.

## Управление

- **W / A / S / D** — движение
- **Shift** — бег
- **F** — фонарь
- **E** — взаимодействие с предметами и дверями
- **Esc** — пауза; повторный выбор «Начать / продолжить» возвращает в игру
- **Мышь** — обзор (браузер попросит разрешить захват указателя)

## Текущие системы

- Главное меню с фоном приоткрытого лифта, тёмного коридора, scanlines и VHS-дрожанием.
- Процедурные материалы с отдельными bump- и roughness-картами для бетонных, стальных и окрашенных поверхностей.
- Исследование комплекса, ключ-карты L-1/L-2, фонарь с разряжаемой батареей, предметы для подбора, двери, мини-карта и архив персонала.
- Настройки качества, теней, экспозиции, громкости и чувствительности мыши сохраняются локально в браузере.

## Проверки

После установки Node.js выполните:

```sh
npm test
```

Это dependency-free smoke test: проверяет связь HTML/CSS/JS, ключевые точки игрового ядра, PBR-карты, ссылки на фон меню и синтаксический разбор JavaScript. Он не заменяет проверку рендеринга в реальном браузере, тестирование WebGL, аудио или полного игрового прохождения.

## Технические заметки

- Внешние библиотеки не устанавливаются через npm; Three.js загружается с CDN.
- Настройки хранятся в `localStorage`. Состояние прохождения пока не является полноценной системой сохранений.
- При проблемах с загрузкой 3D-движка обновите страницу и проверьте доступ к CDN.
