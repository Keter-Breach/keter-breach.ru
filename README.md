# PROJECT: KETER

Браузерный VHS survival-horror прототип в эстетике внутренней системы наблюдения Фонда SCP. Проект можно запускать в браузере или как отдельное Windows-приложение.

## Быстрый запуск в браузере

Откройте `index.html` через локальный статический сервер или опубликованную версию. Three.js и шрифты пока загружаются с CDN, поэтому для полного запуска требуется интернет-доступ и поддержка WebGL.

## Windows-приложение

На Windows 10/11 с установленным Node.js 20+ из корня репозитория:

```sh
npm install
npm run desktop:start
```

Чтобы собрать установщик Windows x64 (.exe):

```sh
npm run desktop:win
```

Готовый установщик появится в папке `dist/`. Для сборки нужны интернет и инструменты npm. Сборка через GitHub Actions: откройте **Actions → Build Windows desktop app → Run workflow**; после успешного завершения скачайте artifact `project-keter-windows-installer`. Ручной запуск workflow пока не выполняется автоматически при каждом push, чтобы не тратить ресурсы на ненужные сборки.

**Важно:** это первый этап упаковки текущей Three.js-игры в настольное окно, а не переход на новый 3D-движок. Electron улучшает удобство запуска, но сам по себе не повышает качество графики. Three.js и шрифты всё ещё загружаются с CDN, поэтому полностью автономный запуск будет следующим этапом. Реалистичность графики будем улучшать отдельно: освещение, туман, постобработка, материалы и детализация окружения; более крупный переход на Unity/Unreal стоит делать только если прототип упрётся в ограничения текущей архитектуры.

## Управление

- **W / A / S / D** — движение
- **Shift** — бег
- **F** — фонарь
- **E** — взаимодействие с предметами и дверями
- **Esc** — пауза
- **Мышь** — обзор (разрешите захват указателя)

## Проверки

```sh
npm test
```

Smoke test проверяет HTML/CSS/JS и ключевые точки игрового ядра. Он не заменяет полноценный запуск Electron, WebGL и полное прохождение игры.
