# PROJECT: KETER

Браузерный VHS survival-horror прототип в эстетике внутренней системы наблюдения Фонда SCP. Текущая игровая версия построена на Three.js; Electron используется для Windows-сборки.

## Запуск в браузере

Откройте опубликованную версию или запустите проект через локальный статический сервер. В браузере Three.js загружается из CDN с фиксированной версией, поэтому для первого запуска требуется интернет и поддержка WebGL. Игровые скрипты, стили, текстуры и аудио находятся в репозитории.

## Windows-приложение

Требования для локальной сборки: Windows 10/11, Node.js 20+ и npm.

```sh
npm install
npm run desktop:start
```

Сборка установщика Windows x64:

```sh
npm run desktop:win
```

Установщик появляется в `dist/`. GitHub Actions выполняет smoke-тесты, собирает NSIS-установщик и публикует его как artifact `project-keter-windows-installer`. Артефакты CI хранятся ограниченное время; старые ссылки на сборки могут истечь.

## Автономная работа

В Electron Three.js берётся из локальной зависимости `node_modules/three`, включённой в установщик. Поэтому после установки настольная версия не должна обращаться к CDN за самим 3D-движком. Установка зависимостей и сборка по-прежнему требуют интернет-доступа. Браузерная версия использует CDN-fallback, поскольку статический хостинг не публикует `node_modules`.

Это упаковка существующей Three.js-игры, а не миграция на Godot. Electron не заменяет оптимизацию графики и не гарантирует одинаковую производительность на всех устройствах.

## Управление

- **W / A / S / D** — движение
- **Shift** — бег
- **F** — фонарь
- **E** — взаимодействие с предметами и дверями
- **Esc** — пауза
- **Мышь** — обзор; игра использует Pointer Lock, а при его недоступности — резервный режим управления

## Проверки

```sh
npm test
```

Smoke-тест проверяет подключение ресурсов, ключевые точки игрового ядра, JavaScript-синтаксис и отдельные регрессии. Он не заменяет ручной запуск Electron, проверку WebGL и полное прохождение игры.
